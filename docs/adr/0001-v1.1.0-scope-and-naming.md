# ADR-0001：V1.1.0 范围、命名与平台边界

- 状态：已接受
- 日期：2026-10-19
- 决策人：项目所有者 + Harness

## 背景

Linux 版 QQ Agent 已在生产运行（V1.0.0，`a2f08e8`）。工作台继承自 Windows 参考项目，存在失效入口、Linux 无意义页面、模块管理入口不清晰等问题；同时真实负载下出现过两次堆溢出。

## 决策

1. **V1.1.0 范围**：稳定性（OOM 观测与缓解）+ 工作台信息架构 + 模块启用/禁用/重载 + 平台边界 + 工程化（测试/CHANGELOG/ADR）。
2. **暂不做**：物理删除模块、微信接入、多平台落地、插件沙箱、大规模提示词改造。
3. **命名**：产品显示名 **TamsuiShore QQ Agent**，中文副标题 **淡水海边**；仓库名与远程地址保持不变，避免链接与历史失效。
4. **外部服务**：`kondius.cn` 相关入口（Skill 市场、插件市场、人设广场、意见收集、官网）保留，但统一标注“外部”并注明需联网；后续增加独立的“外部链接”页。
5. **模块管理**：只做启用/禁用/重载；不做物理删除。现有后端 `POST /api/skills/:id` 已支持 `{enabled}`，本次只改善可发现性。
6. **Windows 版**：同一仓库演进，先建立 `src/platform/` 边界；等 Windows 代码真实出现后再评估 monorepo 拆分，不现在拆独立仓库。

## 影响

- UI：品牌、导航、外部标记、隐藏 Linux 无意义的 SnowLuma 页签。
- 后端：本阶段不改协议；后续模块管理沿用 `/api/skills/:id`。
- 数据：无迁移。
- 部署：开发在 `develop/v1.1.0`，验证后再部署生产。

## 风险与回滚

- 风险：UI 改动可能影响布局/事件绑定；隐藏页签后若代码仍跳转该页，会显示无高亮的视图。
- 回滚：`git checkout v1.0.0` 重新打包部署；配置未变，无需数据回滚。
